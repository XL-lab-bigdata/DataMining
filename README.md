  > 本书内容涵盖统计描述、相关分析、回归分析、数据降维、关联规则挖掘、分类、聚类、异常检测和集成学习等数据挖掘9大核心领域。通过原理解析、数学推导、流程分析、计算示例和案例演示，精心设计231个图表、47个代码示例及5大类学习模块，遴选45个实践案例，全方位促进读者对内容的理解和掌握。此外，本书还配套丰富的数字化学习资源和全套教辅资料，形成了理论与实践并重的立体化教学体系。
